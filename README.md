# React ToDo List

**React ToDo List** is a comprehensive task management application built with React and Redux. It includes various features such as task addition, deletion, completion marking, and hiding completed tasks. The application also leverages Redux for state management, utilizes Redux Saga for handling side effects, and integrates React Router DOM for navigation between different sections of the app.

## Features

- **State Management:** Uses Redux for managing the application state.
- **Redux Store:** Includes a custom Redux store for centralized state management.
- **Redux Saga:** Handles side effects and action dispatching using Redux Saga.
- **Task Management:** Allows adding, deleting, marking tasks as completed, and hiding completed tasks.
- **Complete All Tasks:** Option to mark all tasks as completed.
- **Task Navigation:** Integrates React Router DOM for navigation between two tabs: Tasks and About.
- **Task Details:** View detailed content of individual tasks.
- **React Hooks:** Utilizes hooks like `useNavigate` and `useLocation` for navigation to the task details page and for location tracking.
- **Local Storage:** Saves tasks to `localStorage` to persist data across page refreshes.
- **Sample Tasks:** Fetches a list of sample tasks using `async/await`.
- **Styled Components:** Uses Styled Components for custom styling of the application.
